BaginCam - tiga pilihan UI gabungan

Ketiganya memakai dasar gaya iPhone (layar bersih, satu laci pengaturan). Bedanya hanya di mana angka dan kontrol manual gaya kamera pro ditaruh. Gambar skema, bukan tampilan final.

Pilihan A - Strip angka Angka eksposur selalu tampil kecil di atas zoom. Ketuk angka untuk mengubahnya.

Pilihan B - Saklar PRO Layar bersih seperti iPhone. Satu tombol PRO menyalakan lapisan kamera pro di atasnya.

Pilihan C - Laci manual Layar bidik tidak berubah sama sekali. Kontrol manual jadi baris pertama di dalam laci.
